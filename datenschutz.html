02 — Hosting & Server-LogsWas der Server sieht

Diese Website wird über Vercel (Vercel Inc., USA) ausgeliefert; die zugrunde liegende Server-Infrastruktur wird bei der Hetzner Online GmbH (Deutschland) betrieben. Quellcode und Deployment laufen über GitHub (GitHub, Inc., USA). Beim Aufruf der Seite verarbeiten diese Anbieter automatisch technisch notwendige Zugriffsdaten (u. a. IP-Adresse, Datum und Uhrzeit, abgerufene Datei, Browsertyp). Rechtsgrundlage ist das berechtigte Interesse an einem sicheren und stabilen Betrieb (Art. 6 Abs. 1 lit. f DSGVO). Soweit dabei Daten in die USA übertragen werden, geschieht dies auf Grundlage der EU-Standardvertragsklauseln.

03 — SchriftenSelbst gehostet

Die verwendeten Schriftarten werden lokal vom eigenen Server ausgeliefert. Es besteht keine Verbindung zu Google Fonts oder anderen Dritt-Servern; beim Laden der Schriften wird keine IP-Adresse an Dritte übertragen.

04 — KontaktformularFormspree

Das Kontaktformular wird über den Dienst Formspree (Formspree, Inc., USA) abgewickelt. Wenn Du das Formular absendest, werden die von Dir eingegebenen Daten (Anrede, Titel, Name, E-Mail-Adresse, Hintergrund und Nachricht) über Formspree an ein Postfach weitergeleitet. Rechtsgrundlage ist Dein Wunsch zur Kontaktaufnahme sowie mein berechtigtes Interesse an der Beantwortung (Art. 6 Abs. 1 lit. a und f DSGVO). Die Daten werden nur zur Bearbeitung Deiner Anfrage genutzt und nicht zu Werbezwecken ausgewertet. Details: Formspree Privacy Policy.

05 — ForumGitHub Discussions via giscus

Der Forumsbereich (Sektion „The Forum“) bindet GitHub Discussions über den quelloffenen Dienst giscus ein. Erst wenn Du diesen Bereich nutzt, wird eine Verbindung zu Servern von GitHub, Inc. (USA) aufgebaut und ein Skript von giscus geladen; dabei wird u. a. Deine IP-Adresse an GitHub übermittelt. Zum Mitlesen ist kein Konto erforderlich; zum Mitschreiben und Reagieren benötigst Du einen kostenlosen GitHub-Account und meldest Dich über GitHub an. Für diese Verarbeitung gilt die Datenschutzerklärung von GitHub. Rechtsgrundlage ist das berechtigte Interesse an einem offenen, moderierbaren Diskussionsraum (Art. 6 Abs. 1 lit. f DSGVO). Details: GitHub Privacy Statement.
